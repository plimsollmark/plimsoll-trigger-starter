# Working on this starter

Read the [plimsoll agent guide](https://github.com/plimsollmark/plimsoll/blob/main/AGENTS.md)
for its execution and isolation rules. Keep credentials out of this repository.

Run `npm ci`, `npm run typecheck`, and `npm run deploy -- --dry-run` before a
commit. The deployed trial is opt-in because it needs a reachable daemon and
Trigger.dev project credentials. Its task uses no AI model.
